# Security

If you find a security problem (for example a way to read the private dashboard, tamper with the data, or abuse the
report form), please report it privately through GitHub's
[private vulnerability reporting](https://github.com/lslaoang/ph-politicians/security/advisories/new) instead of a
public issue. Please don't test against the live site in ways that could affect visitors.

Factual errors in the data are not security issues: use the "Report an error" button or a correction issue.
